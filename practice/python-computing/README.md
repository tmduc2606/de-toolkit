# Python Computing

Notebook modules on Python fundamentals that data engineering work leans on
daily — generators, iterators, regex, recursion, file I/O, and string handling.

> Sibling modules with a different purpose: `dsa_de/` (LeetCode-style problems
> with tests), `data_cleaning/` (pandas wrangling chapters). This folder is
> concept learning — read, run, adapt.

| Notebook | Topic |
|---|---|
| `Python-Generators.ipynb` | Lazy sequences and `yield` |
| `Python-Iterators.ipynb` | Iteration protocol and custom iterators |
| `Python-RegEx.ipynb` | Regular expressions for parsing |
| `Functions-External_Libraries-File_IO.ipynb` | Functions, libraries, file I/O |
| `String-manipulation.ipynb` | String processing patterns |
| `Additional_Topic_Recursion.ipynb` | Recursion |

## Run

```bash
uv sync
uv run jupyter lab
```
