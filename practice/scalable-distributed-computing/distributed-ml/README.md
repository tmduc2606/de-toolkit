# Distributed ML — OOP & ML Fundamentals

Object-oriented programming and from-scratch ML notebooks (linear regression,
perceptron, softmax regression, neural net) — the computational building blocks
behind scalable/distributed ML systems.

> Sibling modules with a different purpose: `dsa_de/` (LeetCode-style problems
> with tests), `data_cleaning/` (pandas wrangling chapters). This folder is
> concept learning — read, run, adapt.

| Notebook | Topic |
|---|---|
| `Classes_OOP.ipynb` | Classes and OOP patterns |
| `linear_regression.ipynb` | Linear regression from scratch |
| `perceptron.ipynb` | Perceptron classifier |
| `softmax_regression.ipynb` | Multiclass softmax regression |
| `simple_neural_net.ipynb` | Minimal neural network |

## Run

```bash
uv sync
uv run jupyter lab
```
