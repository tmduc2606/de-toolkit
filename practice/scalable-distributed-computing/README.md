# Scalable & Distributed Computing — OOP & ML Fundamentals

Object-oriented programming and from-scratch ML notebooks (linear regression,
perceptron, softmax regression, neural net) — the computational building blocks
behind scalable/distributed ML systems. Mirrors the theory under
`docs/study-materials/scalable-distributed-computing/`.

> Sibling modules with a different purpose: `dsa_de/` (LeetCode-style problems
> with tests), `data_cleaning/` (pandas wrangling chapters). This folder is
> concept learning — read, run, adapt.

| Notebook | Topic |
|---|---|
| `lecture-3-oop/Classes_OOP.ipynb` | Classes and OOP patterns |
| `lecture-3-oop/linear_regression.ipynb` | Linear regression from scratch |
| `lecture-3-oop/perceptron.ipynb` | Perceptron classifier |
| `lecture-3-oop/softmax_regression.ipynb` | Multiclass softmax regression |
| `lecture-3-oop/simple_neural_net.ipynb` | Minimal neural network |

## Run

```bash
uv sync
uv run jupyter lab
```
